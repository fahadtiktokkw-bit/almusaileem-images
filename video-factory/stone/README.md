# إنتاج فيديو كتالوج المسيليم

يشتغل تلقائيًا عند تحديث أي ملف بهذا المجلد على main، أو يدويًا من Actions → Almusaileem Stone Video → Run workflow.

- عدّل catalog.json للنصوص والموديلات. القالب يحتاج 3 موديلات بالضبط.
- صور العرض في assets، ولكل صورة png مصغرة باسم -thumb.png.
- النتيجة الثابتة: videos/stone/latest.mp4 وpreview.jpg.
- المواصفات: 1080×1920، 15 ثانية، 30 إطارًا بالثانية، بدون صوت.
- يبدأ بفحص وإخراج HyperFrames. عند فشل مسار المتصفح، يستخدم إخراجًا محليًا من نفس HTML وخط GSAP الزمني عبر Chrome وFFmpeg.
- يتحقق من المدة والمقاس وعدد الإطارات وفك ترميز الفيديو كاملًا قبل حفظه.
- run.json يبيّن مسار الإخراج الفعلي وهل نجح فحص HyperFrames الكامل.
- يحتفظ GitHub بسجل آخر التشغيلات، والمرفقات 30 يومًا. آخر فيديو محفوظ بالمستودع.
- لا يحتاج مفاتيح API ولا خدمات صوت أو ذكاء اصطناعي مدفوعة. لا ينشر على حسابات التواصل.
