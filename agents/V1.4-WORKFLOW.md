# Almusaileem Prompt Agent V1.4: Vision Review + Corrective Prompt

Workflow:
1. Run V1.3 video_audit.py with --vision, --reference and OPENAI_API_KEY. This sends the source image and three sampled frames to the OpenAI API. API access and billing are required.
2. Inspect the JSON review manually. It is not proof of full-frame compliance.
3. Generate a correction:
```bash
python agents/corrective_prompt.py --report report.json --allowed-motion "clouds and camel only" --duration 10 --output correction.txt
```
4. Submit correction.txt together with the original image to the video generator. The tool does not directly control Grok.

Tests:
```bash
cd agents && python -m unittest -v test_corrective_prompt.py
```

Limitations: The correction generator is deterministic, not an independent vision model. It requires a genuine semantic_review object; it refuses to invent one from metadata alone. Video audit samples only three frames and does not identify all changes. Reports must be checked by a person.
